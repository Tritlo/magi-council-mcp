# 0019 — Add an optional Copilot member

Add GitHub Copilot as a member through the official `@github/copilot` native ACP mode (`--acp`). Keep Claude, Codex, and Grok in the default council roster. `MAGI_COUNCIL_MEMBERS` controls the roster, so Copilot is available without replacing Grok or adding cost to every default council call.
