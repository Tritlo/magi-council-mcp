# Magi Council

Magi Council lets one host agent consult and direct other model agents.

## Language

**Member**:
A model agent with a built-in integration. A member can be outside the council roster.

**Council roster**:
The supported members that are enabled for one server process, before the host is excluded.
_Avoid_: Default council, member list

**Active advisor**:
A member in the council roster that is not the host.
_Avoid_: Active member

**Host**:
The agent that connects to the server and leads the deliberation. The host is not an active advisor.
_Avoid_: Lead member
